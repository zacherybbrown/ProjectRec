Project Rec is a social experience game with seamless transitions between user-created rooms.

Core concept:
- Players connect to public or private rooms hosted on their own computers.
- A sky train system moves players between rooms, with smooth boarding and transport.
- Rooms appear in a room list only when they are connected and available.

Sky train rules:
- Players can call a sky train at any time to move to another room.
- Public trains allow each player to choose which destination to exit at.
- Private trains use a harness and lock player movement while boarding and transporting.
- Public trains lower a platform down to the players floor level before boarding.
- Trains must not no-clip through world geometry.

Room creation and hosting:
- If a user creates a room in-game while on PCVR, that user launches their own server.
- If the user is not on PCVR, room creation is denied.
- Each connected room is added to the available rooms list dynamically.

Avatar and cosmetics:
- Project Rec includes a base avatar.
- Rooms may provide costumes.
- Core game supports cosmetics in addition to room-specific outfits.

Technical direction:
- Built in Rust.
- Compiled to a native executable.
- Supports PC and PCVR hosting modes.
- Not built with a game engine.
- Does not require administrator privileges to run server or client.

Additional ideas:
- Add a desktop GUI for room hosting, joining, and status display.
- Support PC mode alongside PCVR for local room creation.
- Add room themes and dynamic invitations.
- Add local asset customization and room-specific cosmetics.

Notes:
- Follow the AI guidelines: no em dashes, no shortcuts, no wasted space.
